# 手机远控接入与验收

当前实现让手机作为本机 Cursor BYOK 活动任务的远程入口。电脑继续运行 Cursor、模型请求和工具。手机不能新建任务、续聊已结束任务或处理权限审批。

## 本地开发

```text
apps/mobile/                 独立手机 PWA，访问同源 /api
apps/desktop/                本机设置、配对确认和项目授权
server/src/remote/           独立监听、设备认证、受限展示与命令
server/src/store/remote.rs   手机展示、设备及命令回执持久化
```

1. 安装 `apps/desktop` 和 `apps/mobile` 的 npm 依赖。
2. 执行 `npm --prefix apps/desktop run build:bundle`，生成桌面与手机静态资源。
3. 使用桌面开发或打包命令运行应用。手机资源由独立远控端口提供，主管理端口不对外发布。
4. 当前分支不包含任何自动 GitHub 发布操作；不需要发布 Release 才能本机测试。

## Tailscale 接入

手机、Windows 电脑分别安装并登录自己的 Tailscale 私网。确认电脑已在线，先查看 `tailscale serve status`，避免覆盖已有服务配置。

桌面设置中的“手机远控”默认关闭。填写实际的 Tailscale HTTPS 来源，例如 `https://computer.example.ts.net`，选择要授权的工作区，保存。只有实际收到的 Cursor 请求带有工作区路径后，项目才会出现在列表中。多根工作区需要全部勾选。

检查端口与现有 Serve 配置后，在电脑终端执行：

```text
tailscale serve --bg --https=443 http://127.0.0.1:43127
```

如果修改远控端口，应替换命令中的 `43127`。这是私网 Serve；请同时在 Tailscale 访问策略中限制允许访问的用户和设备。不要启用 Funnel，不要代理完整桌面管理端口。

打开远控开关并保存，确认监听状态无错误。端口冲突时远控保持不可用，不会随机切换端口。点击生成配对链接，手机扫描二维码，填写设备名称，再回电脑确认该设备。票据五分钟有效且只能兑换一次；长期设备凭据由浏览器 Secure/HttpOnly/SameSite Cookie 保存，不进入二维码或 localStorage。

## 使用边界

- 从电脑正常发起已有配置的 BYOK 模型任务，再由手机查看。
- 历史范围是接入后捕获的原始用户输入与受限输出，不导入全部 Cursor 历史聊天。
- 追加会立即中断当前生成和需要中断的工具，再把纯文本要求加入同一次运行；最大 16 KiB UTF-8。
- “已接收”表示命令已持久化，“已应用”依据本机执行确认。网络错误时可能显示结果未知；应用不会自动重发写命令。
- 普通 AskQuestion 可以回答；Shell/文件/MCP 等权限确认仍在电脑进行。
- 停止不回滚已写文件，也不能保证操作系统的所有派生进程停止。
- 手机退出、断网或关闭远控不会取消电脑任务。停止任务必须显式点击停止。
- 显示内容有大小限制并标识截断；快照水位过期会重新获取快照。PWA 只缓存静态应用壳，不缓存会话与认证数据。
- 无锁屏推送保证。电脑睡眠、Cursor 断开或进程重启后必须重新验证状态。
- 桌面撤销设备会关闭其流并拒绝后续操作。取消项目授权后，该项目不再返回给手机。

## 尚需真实设备验收

以下项目必须使用真实 Cursor 与手机完成，自动测试不能替代：

- [ ] 记录 Windows、Cursor、Android/iOS、浏览器版本及浏览器/PWA模式。
- [ ] 手机蜂窝网络经过 Tailscale HTTPS 完成配对和电脑确认。
- [ ] 电脑真实 BYOK 任务包含终端输出，手机前台一秒内看到更新（记录实测延迟）。
- [ ] 手机追加后，电脑显示相同用户消息，仍在同一会话继续。
- [ ] 手机回答普通提问后，电脑提问显示已处理；两端同时回答只有首个有效答案生效。
- [ ] 手机停止后，电脑运行取消，正在执行的工具收到相应中断；下一次电脑继续历史一致。
- [ ] 手机断网、切后台、恢复以及关闭远控均不影响电脑当前任务。
- [ ] 撤销设备与取消项目授权对已有实时流生效。
- [ ] 单文件便携 EXE 无旁置 mobile 目录也能提供手机页面。

在上述真机项目通过前，当前成果应视为待联调实现，不能称为首版验收完成。
